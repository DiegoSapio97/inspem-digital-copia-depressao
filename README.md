# INSPEM Digital — Depressão

Cópia do site [inspem-digital-copia](https://github.com/DiegoSapio97/inspem-digital-copia) voltada para psicoterapia da **depressão**. Construída em [Astro](https://astro.build).

O código é o mesmo do original. As fotos da clínica são baixadas automaticamente no `npm install` a partir do repositório original (o GitHub MCP não envia arquivos binários).

## Como rodar

Requer Node.js 22.12 ou superior.

```sh
npm install
npm run dev
```

| Comando | O que faz |
| --- | --- |
| `npm install` | Instala dependências e baixa as fotos da clínica |
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção em `./dist/` |
| `npm run preview` | Preview do build local |
