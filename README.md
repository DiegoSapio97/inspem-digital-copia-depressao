# INSPEM Digital — Depressão

Cópia do site [INSPEM Digital](https://github.com/DiegoSapio97/inspem-digital-copia) voltada para psicoterapia da **depressão**. Construída em [Astro](https://astro.build).

## Como rodar

Requer Node.js 22.12 ou superior.

```sh
npm install
npm run dev
```

| Comando | O que faz |
| --- | --- |
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção em `./dist/` |
| `npm run preview` | Preview do build local |
